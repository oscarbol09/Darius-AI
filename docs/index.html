Installation & Getting Started

Darius AI runs either as a standalone natively compiled Windows installer or directly from a Python virtual environment.

Best if you want to run Darius AI immediately with zero Python or compiler dependencies:

  1. Download DariusAI-Setup-Latest.exe from GitHub Releases.
  2. Run the installer. It installs cleanly into your user directory (%LOCALAPPDATA%\Programs\DariusAI) with no UAC administrator prompt.
  3. Launch Darius AI from the Start Menu or Desktop shortcut.

Requirements: Windows 10/11 and Python 3.11 or 3.12.

PowerShell 
# 1. Clone the repository
git clone https://github.com/oscarbol09/Darius-AI.git
cd Darius-AI

# 2. Create and activate virtual environment
python -m venv .venv
.venv\Scripts\activate

# 3. Install dependencies
pip install -r requirements.txt

# 4. Launch Darius AI
python main.py
💡
First-Run Tip: Open ⚙ Settings (top bar or Ctrl+,) to switch between English (en) and Español (es), add your BYOK API key, and choose your preferred TTS voice. Keys are encrypted at rest via Windows DPAPI.

Autonomous Deep Research

Implemented in deep_research_agent.py, Darius orchestrates multi-source web synthesis:

  1. Decomposes the topic into 3 orthogonal search queries.
  2. Performs non-blocking DuckDuckGo web extraction sanitized via BeautifulSoup4 and Anti-SSRF checks.
  3. Synthesizes a cited report using numbered references [1], [2].
  4. Archives the final Markdown dossier directly into your Obsidian Vault.

Multi-Step Agent Planner

agent_planner.py breaks complex goals into atomic execution steps, chaining previous results forward via the {{PREV}} context token and tokenized multi-key hotkeys:

Execution Trace Example 
User: "Create a plan for researching WebGPU shaders and launching dev mode"

  1. [deep_research] Synthesizes and archives WebGPU shader benchmarks to Obsidian.
  2. [workspace_dev] Focuses Cursor IDE on monitor 1 and docs on monitor 2.
  3. [talk] Confirms the workspace is ready.

Obsidian Memory Brain

All knowledge stays local in plain Markdown files enriched with YAML frontmatter inside your Obsidian Vault:

  • Daily Journal (Diario/YYYY-MM-DD.md): Records timestamped notes spoken or typed on demand.
  • Permanent Memories (Darius/Memorias/): Saves key facts, architecture decisions, and user preferences.
  • Automatic Context Injection: Retrieves relevant vault notes on every AI query to ground answers in your personal workspace.

Structured Intelligence Dossiers (OSINT)

Perceptual Presence Sentinel

webcam_sentinel.py runs a passive low-FPS (1–2 FPS) background monitor under 1% CPU utilization:

Event Condition Triggered Action
User Arrived (on_user_arrived) Face detected after prolonged absence (2-frame debounce) Wakes the assistant and triggers the Darius Welcome Protocol.
Extended Absence (on_user_left) No presence detected for > 120 seconds Pauses active media playback or activates idle sleep mode.
Shoulder Surfer (on_shoulder_surfer) More than one face detected in frame Emits a discreet acoustic privacy alert.

In-Memory Procedural Sound Effects

sound_effects.py synthesizes crisp tactical audio cues (sine, square, triangle waveforms) directly in RAM with NumPy and sounddevice:

  • 0 KB Disk Assets: Zero external .wav or .mp3 asset files shipped.
  • Sub-5ms Latency: Non-blocking playback with anti-clipping envelopes.
  • Interactive Toggle: Mute or unmute procedural FX via the HUD or voice commands.

Multi-Engine Voice & Synthesis (TTS) + SHA-256 Cache

Voice synthesis runs asynchronously off the UI thread through a COM-safe worker queue (tts_worker.py) with immediate Escape Barge-In across all engines:

  1. ElevenLabs (High-Fidelity Neural): 24kHz PCM streaming with disk caching.
  2. Edge-TTS (Free Neural Cloud): Natural English (en-GB-RyanNeural, en-US-JennyNeural) and Spanish (es-MX-DaliaNeural, es-ES-AlvaroNeural) voices selected automatically from your i18n locale.
  3. Windows SAPI5 (Offline Native): Zero-latency offline fallback built into Windows.
💾
SHA-256 Audio Cache: Recurring acknowledgments are hashed and cached locally on disk for instant replay with zero API quota spend.
