Instalación & Puesta en Marcha

Darius AI se puede utilizar tanto mediante su instalador standalone compilado en C nativo como a través de su entorno de desarrollo en Python.

Ideal si deseas usar Darius AI de inmediato sin necesidad de tener Python ni compiladores instalados en tu computadora:

  1. Descarga el instalador DariusAI-Setup-v7.0.0.exe desde Releases de GitHub.
  2. Ejecuta el archivo. El asistente se instalará de forma aislada en tu perfil de usuario (%LOCALAPPDATA%\Programs\DariusAI) sin requerir permisos de administrador.
  3. Lanza Darius AI desde el menú de inicio o el acceso directo del escritorio.

Requisitos: Windows 10/11 y Python 3.11 o 3.12.

PowerShell 
# 1. Clonar el repositorio
git clone https://github.com/oscarbol09/Darius-AI.git
cd Darius-AI

# 2. Crear y activar entorno virtual
python -m venv .venv
.venv\Scripts\activate

# 3. Instalar dependencias
pip install -r requirements.txt

# 4. Iniciar el asistente
python main.py
💡
Tip de Inicio: En la primera ejecución, pulsa el botón ⚙ Configuración en la esquina inferior izquierda para ingresar tu clave de API (Gemini, OpenAI, Groq, etc.) y seleccionar tu voz preferida.

Vista Propósito Capacidades Clave
💬 Conversación Consola principal de chat e interacción Historial en tiempo real, transcripción de voz, burbujas coloreadas por rol y estado acústico.

Visión Multimodal & OCR (<15ms)

El módulo screen_vision.py permite a Darius AI observar lo que ocurre en tu pantalla en tiempo real mediante captura directa Win32 GDI con mss, compresión JPEG adaptativa en memoria (~150-250 KB) y codificación Base64 sin escrituras a disco.

Comandos de Voz / Texto 
"¿Qué hay en mi pantalla?"        # Análisis contextual del monitor activo
"Analiza este error en pantalla"  # Diagnóstico visual de stacktraces y diálogos
"Lee el texto de mi pantalla"     # Transcripción tipográfica y extracción OCR

Investigación Profunda Autónoma (Deep Research)

Inspirado en flujos de razonamiento autónomo, deep_research.py ejecuta una investigación multi-fuente:

  1. Descompone el tema en 3 consultas ortogonales de búsqueda.
  2. Realiza web scraping no bloqueante en DuckDuckGo con extracción y sanitización vía BeautifulSoup4.
  3. Sintetiza un reporte académico con citas numeradas [1], [2].
  4. Archiva automáticamente el reporte en tu bóveda de Obsidian en Darius/Investigaciones/YYYY-MM-DD - [Tema].md.

Planificador de Agentes Multi-Paso

El subsistema agent_planner.py descompone metas complejas en 1 a 4 pasos atómicos de ejecución, encadenando la salida de un paso al siguiente mediante la variable contextual {{PREV}}:

Ejemplo de Ejecución 
Usuario: "Planifica investigar computación cuántica y preparar el modo desarrollo"
Darius AI:
  1. [deep_research] Genera y archiva informe sobre computación cuántica.
  2. [workspace_dev] Maximiza Cursor en monitor 1 y abre documentación en monitor 2.
  3. [talk] Notifica al usuario que el entorno de trabajo está listo.

Cerebro y Memoria en Obsidian

Darius AI almacena el conocimiento en tu bóveda local de Obsidian en formato Markdown estándar con frontmatter YAML:

  • Diario Personal (Diario/YYYY-MM-DD.md): Registra eventos diarios con marca de tiempo precisa.
  • Memorias Permanentes (Darius/Memorias/): Almacena hechos sobre el usuario, configuraciones y preferencias.
  • Inyección de Contexto: Al consultar a la IA, Darius recupera notas relevantes de tu bóveda para enriquecer el prompt del LLM.
